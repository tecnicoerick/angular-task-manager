
# 🧠 Task Manager SPA (Angular)

Aplicação SPA para gerenciamento de tarefas com Angular, RxJS e API REST.

## 🚀 Como rodar

```bash
npm install
ng serve
```

## 📡 API
```bash
json-server --watch db.json
```

## 📂 Estrutura
src/app organizado por core, features e shared.
